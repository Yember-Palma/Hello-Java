# Proyecto: hello-java

Este proyecto es una colección de ejercicios y ejemplos prácticos de programación en Java, abarcando conceptos fundamentales como lógica de programación, estructuras de control, funciones, POO (Programación Orientada a Objetos), herencia, polimorfismo, abstracción, composición, manejo de excepciones, estructuras de datos y buenas prácticas.

## Estructura del Proyecto

```
hello-java/
├── src/
│   ├── Abstracion/           # Ejercicios de abstracción
│   ├── Composicion/          # Ejercicios de composición
│   ├── Contraseña.java       # Ejercicios de lógica y validación
│   ├── Excepciones/          # Manejo de excepciones personalizadas
│   ├── Extrass/              # Ejercicios adicionales
│   ├── FOR/                  # Bucles for y while
│   ├── Funciones/            # Ejercicios de funciones y métodos
│   ├── Herencia/             # Ejercicios de herencia
│   ├── LogicaProgramacion/   # Ejercicios básicos de lógica
│   ├── Main.java             # Archivo principal de ejemplo
│   ├── Modulo1Master/        # Buenas prácticas y programación imperativa
│   ├── OOP/                  # Programación orientada a objetos
│   ├── Polimorfismo/         # Ejercicios de polimorfismo
│   └── StructuresJava/       # Estructuras de datos (arrays, listas, mapas, sets)
└── README.md
```

## Requisitos

- Java JDK 8 o superior
- Un IDE recomendado: IntelliJ IDEA, Eclipse, VS Code o similar

## Compilación y Ejecución

1. Clona este repositorio o descarga el código fuente.
2. Abre la carpeta en tu IDE favorito.
3. Compila los archivos Java:

   ```sh
   javac -d out src/**/*.java
   ```

4. Ejecuta la clase principal de ejemplo (por ejemplo, HelloWork):

   ```sh
   java -cp out LogicaProgramacion.HelloWork
   ```

Puedes cambiar la clase a ejecutar según el ejercicio que desees probar.

## Ejemplo de Uso

```java
public class HelloWork {
	public static void main(String[] args) {
		System.out.println("hola mundo");
	}
}
```
